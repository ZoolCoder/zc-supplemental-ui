== إعداد الموقع

اضبط سمات AsciiDoc هذه في ملف `antora-playbook.yml`:

[cols="1,3"]
|===
| السمة | الأثر

| `page-zc-repo` | رابط المستودع. يضيف زر GitHub وروابط التذييل.
| `page-zc-pdf` | مسار ملف PDF من جذر الموقع. يضيف زر PDF.
| `page-zc-langs` | اللغات ومكوّناتها، مثل `en=preview ar=preview-ar`. يضيف قائمة اللغات.
|===
