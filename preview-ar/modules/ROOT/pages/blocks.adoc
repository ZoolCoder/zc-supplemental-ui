== الشيفرة

تبقى الشيفرة من اليسار إلى اليمين في كل اللغات:

[source,yaml]
----
version: 1
domains:
  - name: example.com # <1>
    mail:
      provider: purelymail
----
<1> يجب أن يكون النطاق منطقة في حساب Cloudflare الخاص بك.

== الألسنة

[tabs%sync]
======
macOS::
+
[source,console]
----
$ brew install zoolcoder/tap/mailctl
----

Linux::
+
[source,console]
----
$ curl -fsSL https://example.com/install.sh | sh
----
