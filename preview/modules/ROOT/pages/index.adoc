== Configure a site

Set these AsciiDoc attributes in the consuming playbook:

[cols="1,3"]
|===
| Attribute | Effect

| `page-zc-repo` | Repository URL. Adds the GitHub button, the footer links and the sidebar badge.
| `page-zc-pdf` | Path of the PDF from the site root. Adds the PDF button.
| `page-zc-site` | The owner's website, linked from the menu and the footer.
| `page-zc-owner` | The owner's name in the footer.
| `page-zc-tagline` | The line under the product name. Defaults to `Documentation`.
| `page-zc-license` | The licence line. Defaults to `MIT licensed`.
| `page-zc-og-image` | An absolute image URL for link previews.
|===

== Page roles

Three roles shape a landing page:

`[.hero]` on an open block:: Sets its paragraphs as the page's lead.
`[.cta]` on a paragraph of links:: Turns them into buttons. The first is the primary one.
`[.cards]` on a list:: Lays it out as a grid of cards. A card that starts with a link is clickable all over.
