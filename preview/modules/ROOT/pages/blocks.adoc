== Tabs

Tabs hold the same step for different systems. Tabs with the same labels
and the `sync` option change together, and the choice is remembered.

[tabs%sync]
======
macOS::
+
[source,console]
----
$ brew install zoolcoder/tap/mailctl
----

Linux::
+
[source,console]
----
$ curl -fsSL https://example.com/install.sh | sh
----

From source::
+
[source,console]
----
$ go install github.com/zoolcoder/mailctl/cmd/mailctl@latest
----
======

Then check the install:

[tabs%sync]
======
macOS::
+
[source,console]
----
$ mailctl version
----

Linux::
+
[source,console]
----
$ mailctl version
----

From source::
+
[source,console]
----
$ $(go env GOPATH)/bin/mailctl version
----
======

== Admonitions

NOTE: A note carries background a reader may need.

TIP: A tip shortens a task.

IMPORTANT: Important text changes what the reader does next.

WARNING: A warning prevents a mistake that costs time.

CAUTION: A caution prevents a mistake that loses data.
